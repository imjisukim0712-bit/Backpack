# Backpack — VOLATILE 프로토타입

정통 판타지 던전을 내려가는 연금술사 모험가의 인벤토리 로그라이크 **VOLATILE** 프로토타입 저장소입니다.
규칙은 두 줄입니다. 아이템을 옆에 두면 강해지고, 클릭하면 씁니다. 재미는 좁은 가방 안에서 붙일 것과 떼어 놓을 것이 충돌하는 데서 나옵니다.

## 실행 방법

`VOLATILE_v0.8.html` 파일 하나를 브라우저에서 열면 바로 실행됩니다. 서버, 빌드, 외부 의존성이 없습니다.

## 저장소 구성

| 파일 | 내용 |
| --- | --- |
| `VOLATILE_vX.Y.html` | 단일 파일로 실행되는 게임 프로토타입 (버전별) |
| `게임구조.md` | 게임의 전체 구조(시스템, 데이터, 턴 흐름, 화면 구성) |
| `작업내용.md` | 버전별 작업 이력과 변경 사항 |
| `README.md` | 이 문서. 프로젝트 소개와 작업 규칙 |

## 작업 규칙

이 저장소에서 Claude Code로 작업할 때 지키는 규칙입니다.

### 모델과 에이전트
- Fable 모델로 작업할 때는 반드시 **Opus를 보조 에이전트**로 함께 사용합니다. (검토, 병렬 작업, 테스트 등)

### 언어
- 모든 답변과 문서는 **한국어(한글)**로 작성합니다.

### 프로토타입 형식
- 프로토타입은 항상 **단일 HTML 파일**로 만듭니다. 파일 하나만 열면 실행되어야 하며 외부 리소스에 의존하지 않습니다.
- 화면은 **모든 기기와 해상도**(데스크톱, 태블릿, 모바일)에 맞춰 적절히 조절되도록 반응형으로 만듭니다.

### 버전과 산출물
- 구현이 완료될 때마다 **버전을 올립니다**. 파일명은 `게임이름_버전명.html` 형식입니다. (예: `VOLATILE_v0.1.html`)
- 버전을 올릴 때마다 해당 HTML 파일을 **Claude Code 대화창에도 첨부**합니다.

### 커밋과 브랜치
- 구현이 완료되면 **즉시 커밋**합니다.
- 특별한 지시가 없다면 항상 **main 브랜치**에 커밋합니다.

### 문서 유지
- 내용이 업데이트될 때마다 `작업내용.md`에 작업 이력을 적재합니다.
- 게임의 전체적인 구조는 항상 `게임구조.md`에 최신 상태로 적재합니다.

### 새 세션 시작
- 새 세션에서 새 대화를 시작할 때에는 **`작업내용.md`와 `게임구조.md`를 먼저 읽고 파악**한 뒤 작업을 시작합니다.
